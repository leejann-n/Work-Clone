# 수당·공제 기준표

> ※ 본 문서는 업무자동화 실습을 위한 **가상 문서**입니다. 요율·세율은 실제와 다르며 계산 연습용입니다.

- 문서번호: HR-REG-002
- 시행일: 2026-01-01
- 관련 규정: 급여규정(HR-REG-001) 제8조, 제9조

## 1. 통상시급 산정

- 월 소정근로시간: **209시간**
- 통상시급 = (기본급 + 직책수당) ÷ 209
- 식대와 성과급은 통상시급 산정에 포함하지 않는다.
- 원 단위 미만은 **절사**한다.

## 2. 시간외수당 가산율

| 구분 | 조건 | 지급 배율 (통상시급 기준) |
|---|---|---|
| 연장근로 | 1일 8시간 초과, 사전 승인 | 1.5배 |
| 야간근로 | 22:00 ~ 06:00, 사전 승인 | 0.5배 가산 (단독 시 1.5배) |
| 연장 + 야간 중복 | 22:00 이후 연장근로 | 2.0배 |
| 휴일근로 | 8시간 이내 | 1.5배 |
| 휴일근로 | 8시간 초과 | 2.0배 |

예시: 통상시급 20,000원인 직원이 평일 23:00~24:00 승인된 연장·야간근로를 1시간 한 경우 → 20,000 × 2.0 = **40,000원**

## 3. 4대 보험 근로자 부담 요율 (가상)

| 항목 | 요율 | 비고 |
|---|---|---|
| 국민연금 | 4.5% | 과세급여 기준 (식대 제외) |
| 건강보험 | 3.5% | 과세급여 기준 (식대 제외) |
| 장기요양보험 | 건강보험료의 12% | |
| 고용보험 | 0.9% | 과세급여 기준 (식대 제외) |

- 보험료 산정 기준(보수월액) = 기본급 + 직책수당 + 시간외수당 + 성과급 (식대 제외)
- 원 단위 미만은 **절사**한다.

## 4. 소득세 (가상 간이세율)

| 월 과세급여 구간 | 소득세율 |
|---|---|
| 3,000,000원 이하 | 3% |
| 3,000,001 ~ 5,000,000원 | 6% |
| 5,000,001원 이상 | 10% |

- 과세급여 = 기본급 + 직책수당 + 시간외수당 + 성과급 (식대는 월 200,000원까지 **비과세**)
- 지방소득세 = 소득세의 10%
- 원 단위 미만은 **절사**한다.

## 6. 실수령액 계산 순서

1. 지급 총액 = 기본급 + 직책수당 + 식대 + 시간외수당 + 성과급(해당 월)
2. 과세급여 산정 (식대 제외)
3. 4대 보험 공제
4. 소득세·지방소득세 공제
5. 실수령액 = 지급 총액 − 공제 합계
