# 양식: 회의 결과 보고 메일

> ※ 가상 문서입니다. 과거 발송 양식 샘플.

## 작성 규칙
- 수신자: 회의 소집자, 결재권자, 관련 팀장
- 제목 형식: `[회의결과] {회의 주제} ({YYYY-MM-DD})`
- 본문 순서: 요약 → 결정 사항 → Action Item → **규정·기존 업무와의 관계** → 확인 요청 사항
- 규정이나 과거 결정과 충돌하는 내용이 있으면 반드시 "확인 요청 사항"에 근거 조항과 함께 적는다.
- 어조는 존댓말, 3문장 이내 요약으로 시작한다.

## 예시

**제목**: [회의결과] 야근 수당 산정 기준 정리 (2026-06-18)

안녕하세요, 이서연입니다. 6월 18일 회의 결과를 공유드립니다.

**요약**
야근 수당 산정 시 연장·야간 중복 배율과 사전 승인 절차를 명확히 정리했습니다.

**결정 사항**
1. 22시 이후 연장근로는 통상시급 2.0배 적용
2. 긴급 장애 대응은 익일 12시까지 사후 승인 허용

**Action Item**
- 한도윤 팀장: 야근 사전 승인 양식 공유 (6/25)
- 이서연: 6월 급여 야근 수당 재검증 (6/24)

**규정·기존 업무와의 관계**
기준표(HR-REG-002) 변경은 없으며, 6월 급여 처리에 즉시 영향이 있는 사항은 없습니다.

**확인 요청 사항**
없음

감사합니다.
